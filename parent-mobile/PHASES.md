# Parent Mobile Phases

## Phase 1 - Core Scaffold

Goal: establish the parent-first mobile shell and the main information hierarchy.

Deliverables:
- `Home` screen with active child, alert strip, and weekly snapshot
- `Academics` screen with overall average and subject list
- `Attendance` screen with rate, totals, and recent records
- `Messages` screen with simple thread list and unread counts
- `More` tab for profile and lower-priority items
- Shared child switcher and reusable summary cards

Success criteria:
- Parents can understand the child status within a few seconds
- The app avoids subject-first and admin-first language
- Core navigation matches parent goals

## Phase 2 - Detail Layers

Goal: add deeper views without cluttering the first screen.

Deliverables:
- Subject detail page
- Attendance detail timeline
- Message thread view
- Notification center

Success criteria:
- Users can drill down from summaries to details in one tap
- Secondary information stays out of the main dashboard

## Phase 3 - Actionability

Goal: help parents act on what they see.

Deliverables:
- Quick actions for common tasks
- Deep links from alerts into relevant screens
- Empty states with guidance and next steps

Success criteria:
- Important issues are one tap away
- Empty states tell parents what to do next

## Phase 4 - Polishing

Goal: improve clarity, trust, and long-term engagement.

Deliverables:
- Performance trends
- Parent-friendly insights
- Refined visual hierarchy
- Accessibility pass

Success criteria:
- The app feels calm, clear, and useful on mobile
- Parents get interpretation, not just raw data
