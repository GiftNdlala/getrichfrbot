# Parent Mobile

Phase 1 scaffold for the parent-first mobile experience.

## Current focus

- Home with active child, alerts, and weekly snapshot
- Academics with overall average and subject breakdown
- Attendance with rate, totals, and recent records
- Messages with simple conversation list
- More for profile and secondary actions

## Notes

- This folder is intentionally separate from the trading bot project root.
- The scaffold uses a simple React Native structure so it can be expanded into Expo or bare React Native later.
- The phase roadmap lives in `PHASES.md`.
